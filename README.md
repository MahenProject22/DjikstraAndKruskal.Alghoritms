## 📌 Activity Description

This activity demonstrates the implementation of two important graph algorithms
using the Go programming language:

- **Dijkstra's Algorithm** – used to find the shortest path between vertices in
  a weighted graph.
- **Kruskal's Algorithm** – used to find the Minimum Spanning Tree (MST) of a
  weighted graph.

Both algorithms use the same graph from the given exercise and demonstrate
different approaches to solving weighted graph problems.
